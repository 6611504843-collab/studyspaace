# StudySpace — แอปจัดการงานและตารางเรียน

เว็บแอปสำหรับนักศึกษา สร้างด้วย HTML, CSS และ JavaScript และเผยแพร่ผ่าน GitHub Pages

## ความสามารถ
- เพิ่ม แก้ไข ลบ และค้นหางาน
- กำหนดวันส่งและระดับความสำคัญ
- ทำเครื่องหมายงานว่าเสร็จแล้ว
- เพิ่มและลบวิชาเรียน พร้อมวันและเวลา
- แสดงตารางเรียนรายสัปดาห์
- บันทึกข้อมูลในเบราว์เซอร์ด้วย localStorage
- รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## วิธีเปิดใช้งาน
เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเผยแพร่ด้วย GitHub Pages

## วิธี Deploy ด้วย GitHub Pages
1. สร้าง Repository ใหม่บน GitHub ชื่อ `studyspace`
2. อัปโหลด `index.html`, `style.css`, `script.js` และ `README.md` ไว้ที่ระดับบนสุดของ Repository
3. เข้า Settings → Pages
4. ใน Build and deployment เลือก Source: Deploy from a branch
5. เลือก Branch: `main` และ Folder: `/ (root)` แล้วกด Save
6. รอ GitHub Pages เผยแพร่ จากนั้นกด Visit site เพื่อเปิดเว็บไซต์

## หมายเหตุ
ข้อมูลที่เพิ่มในแอปจะเก็บไว้ใน localStorage ของเบราว์เซอร์และอุปกรณ์นั้น ๆ ยังไม่มีระบบบัญชีผู้ใช้หรือซิงก์ข้อมูลข้ามอุปกรณ์
